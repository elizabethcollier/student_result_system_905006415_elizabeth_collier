# Student Result Management System

A Python program for managing student exam results.

## Features
- Creates student objects.
- Displays student information.
- Displays the system and school names.

## Requirements
- Python 3

## How to Run
Open a terminal in the project folder and run:

```bash
python oop_ass1_elizabethcollier_6415_student_result_system.py
```
